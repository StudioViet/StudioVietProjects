401 / 502
Whose credentials?
Caller 401 stops at the integration. Provider 401 becomes 502 through the integration; the probe preserves the provider’s 401.
409 / 422
Correct the request.
Reuse a key only for the same operation. To see 409, submit successfully, change the body, and execute again without changing the key.
429 / 503 / 504
Retry with intent.
Respect Retry-After. A timeout can hide a completed write. Retry with the same key and body to recover the original result.
