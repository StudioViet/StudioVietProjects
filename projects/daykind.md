# DayKind

**Status:** In Progress

## Problem

Traditional task managers assume time is the main constraint. DayKind explores a different question: what plan is realistic when energy, focus, stress, recovery, and commitments change from day to day?

## Current implementation

The verified prototype is a local-first, single-page web application built with HTML, CSS, and vanilla JavaScript. It stores device-local state with browser localStorage.

The product direction includes:

- Daily capacity inputs
- A capacity-aware plan
- Brain-dump capture and task prioritization
- Explanations for why a recommendation fits the current day
- Guardrails against maximizing today at the expense of tomorrow
