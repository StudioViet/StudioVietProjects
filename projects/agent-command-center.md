# Studio Viet Agent Command Center

**Status:** Pilot / Review

## Problem

A solo operator can generate many ideas and AI outputs without gaining clarity, evidence, or finished work. The Command Center is designed to turn scattered context into reviewable artifacts while keeping consequential judgment with the human owner.

## Workflow design

The operating workflow follows seven stages:

1. Gather confirmed evidence, assumptions, conflicts, and missing information
2. Define one outcome, scope, constraints, and human decisions
3. Specify the audience, format, and acceptance criteria
4. Generate without inventing facts, progress, owners, or dates
5. Review accuracy, risks, privacy, and actionability
6. Improve only the reusable instruction revealed by the review
7. Reuse the stable workflow and version meaningful changes
